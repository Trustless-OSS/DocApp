# 1. Sign in with GitHub

<TimeEstimate minutes={1} forRole="Maintainers" needs="GitHub account" />

**What you'll do:** Sign in to Trustless OSS and connect your GitHub account.

---

## Step 1: Go to Trustless OSS

Visit [app.trustless-oss.xyz](https://app.trustless-oss.xyz) or [dashboard.trustless-oss.xyz](https://dashboard.trustless-oss.xyz).

You'll see a login page.

{/* MEDIA-SLOT
  id: m-signin-01
  type: image
  file: /media/maintainer/signin-page.png
  show: Trustless OSS login page with "Sign in with GitHub" button
  caption: The Trustless OSS login page
  alt: Trustless OSS login page
*/}

---

## Step 2: Click "Sign in with GitHub"

A GitHub authorization popup will appear.

{/* MEDIA-SLOT
  id: m-signin-02
  type: image
  file: /media/maintainer/github-auth.png
  show: GitHub authorization dialog asking for permission to access repositories and user data
  caption: GitHub will ask to authorize Trustless OSS
  alt: GitHub authorization popup
*/}

---

## Step 3: Authorize Trustless OSS

Click **"Authorize"** to let Trustless OSS access your repositories and account info.

You'll be redirected to the Trustless OSS dashboard.

{/* MEDIA-SLOT
  id: m-signin-03
  type: image
  file: /media/maintainer/dashboard-empty.png
  show: Trustless OSS dashboard for a new user (empty repositories list with "Add repository" button)
  caption: Dashboard after sign in. No repositories yet.
  alt: Empty Trustless OSS dashboard
*/}

---

## Done

You're now signed in. The dashboard is empty because you haven't connected any repositories yet.
