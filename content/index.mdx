# Trustless OSS Documentation

Welcome to the official documentation for **Trustless OSS** — an escrow-backed GitHub bounty system built on the Stellar ecosystem.

## What is Trustless OSS?

Trustless OSS is a platform that enables escrow-backed bounties for open source contributions. It follows the contribution lifecycle maintainers already know, while keeping reward states visible and GitHub as the primary place where work happens.

## Quick Start

<Steps>
  <Step n={1} icon="github" title="Connect your GitHub account">
    Install the Trustless OSS GitHub App on your repositories or organization.
  </Step>
  <Step n={2} icon="wallet" title="Fund a bounty">
    Lock stablecoins (USDC) into escrow against a GitHub issue.
  </Step>
  <Step n={3} icon="merge" title="Merge the proof">
    Review and merge the contributor's pull request when the work is done.
  </Step>
  <Step n={4} icon="reward" title="Release the reward">
    The smart contract pays the contributor automatically.
  </Step>
</Steps>
