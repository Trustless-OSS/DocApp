# Dashboard tour


**What you'll do:** Learn where everything lives, so the task pages make sense in context.

---

## Repositories list

Your landing page after sign-in.

- **Search** by name.
- **Filters:** All / Deployed / Not deployed / Newest / Name A–Z.
- **Pagination:** 15 per page.
- **Add repository:** opens the GitHub App install flow.
- **Sync:** refreshes installation state from GitHub. Press it when a freshly installed repo hasn't appeared.

## Repository page

Everything for one repo.

- **Escrow balance** in USDC, with **Fund**, **Withdraw**, and an **Inspect** link to the on-chain escrow viewer.
- **Reward tiers** — add, edit, delete `(label, amount)` pairs. See [Set reward tiers](/m-05-reward-amounts).
- **Delete** — only enabled when the balance is `0`.
- **Explore bounties** — a table of the repo's bounty issues: issue #, title, level, reward, status, contributor, and a per-row actions menu (Retry / Release / Approve / Reject / Hold).

<Callout type="info">
The row actions mirror the bot commands and the automation: **Release** and **Approve** nudge a payout that's ready, **Reject** disputes and refunds, **Hold** pauses, and **Retry** re-runs the checks. In normal operation you rarely need them — merging the PR is enough.
</Callout>

## Profile

Your public contributor profile and your own payout wallet.

- Editable: name, bio, location, website, skills, and socials (Telegram, Discord, Twitter).
- **Payout wallet:** connect, change, or copy your Stellar address. This is where you receive funds — including the maintainer's share of a split and reject refunds.

---

## Activity, Leaderboard, Notifications

- **Activity:** a ledger of funding, payouts, refunds, and rejections, with filters.
- **Leaderboard:** contributors ranked by earnings.
- **Notifications bell:** bounty assigned, amount missing/updated, insufficient funds, rejected, and payout events.
- **Theme:** light/dark toggle.
