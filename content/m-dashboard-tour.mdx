## Main page (Repositories)

The **Repositories** view is your home on the dashboard.

**Features:**
- **Search:** Find a repo by name
- **Filters:** All / Deployed / Not deployed / Newest / Name A–Z
- **Pagination:** 15 repos per page
- **Add repository:** Button to install the GitHub App on a new repo
- **Sync button:** Refresh repo data from GitHub

## Repository page

Click a repository to open its detail page.

{/* MEDIA-SLOT
  id: m-dashboard-02
  type: image
  file: /media/maintainer/dashboard-repo-detail.png
  show: Repository page with escrow balance, Fund/Withdraw/Delete buttons, reward tiers, bounties table
  caption: A single repository's management page
  alt: Repository detail page
*/}

**Sections:**

### Escrow balance
Shows how much USDC is locked. Quick actions: **Fund**, **Withdraw**, **Delete**.

### Reward tiers
Current bounty amounts (low, medium, high, custom). Click to edit.

### Bounties table
All issues labeled as bounties. Columns: Issue #, Title, Tier, Reward, Status, Contributor, Actions.

**Status values:**
- `Open` — Not yet claimed
- `In progress` — Contributor assigned, waiting for PR
- `PR pending review` — PR open, awaiting merge
- `Completed` — PR merged, payment released
- `Rejected` — Contributor's work rejected
- `Disputed` — Payment hold pending review

**Actions menu** (for each bounty):
- `Retry` — Retry a failed payout
- `Release` — Manually release payment (if PR merged but bot missed it)
- `Approve` — Approve work (manual approval before merge)
- `Reject` — Mark work as rejected
- `Hold` — Temporarily hold a bounty (pause it)

## Notifications

Click the **bell icon** in the top right.

Notifies you of:
- Bounty claimed (new contributor assigned)
- PR opened (linked to bounty)
- Payout failed (retry needed)
- Contributor feedback or disputes

---

## Settings

Click the **gear icon** or **Settings**.

Access:
- Account settings (profile, email)
- Notification preferences
- GitHub App permissions
- Export data

---

## Light / Dark mode

Click the **sun/moon icon** in the top right to toggle themes.

---

## Navigation tips

- **Search is global:** Use Cmd+K / Ctrl+K to search repo names, bounty issues, and contributor names
- **Breadcrumbs:** At the top, shows your current location (Home > Repos > RepositoryName)
- **Back button:** Sidebar collapses by default; expand it to see all pages
