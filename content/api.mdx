# API Reference

Complete API documentation for Trustless OSS. All API endpoints require authentication via API key.

## Authentication

### API Keys

Generate API keys from your [dashboard](https://dashboard.trustless-oss.xyz/settings/api).

```bash
# Include API key in headers
curl -H "Authorization: Bearer YOUR_API_KEY" \
  https://api.trustless-oss.xyz/v1/bounties
```

### Scopes

API keys can be scoped to specific permissions:

| Scope | Description |
|-------|-------------|
| `bounties:read` | Read bounties and transactions |
| `bounties:write` | Create and modify bounties |
| `organizations:read` | Read organization data |
| `organizations:write` | Modify organization settings |
| `webhooks:manage` | Manage webhook subscriptions |

## Base URL

```
https://api.trustless-oss.xyz/v1
```

## Rate Limits

- **Free tier**: 1,000 requests/hour
- **Pro tier**: 10,000 requests/hour  
- **Enterprise**: Custom limits

Headers included in responses:
```http

X-RateLimit-Reset: 1625097600
```

## Endpoints

### Bounties

#### List Bounties
```http
GET /bounties
```

**Parameters**:
- `organization` (string): Filter by organization
- `repository` (string): Filter by repository
- `status` (string): `active`, `completed`, `cancelled`
- `limit` (number): Results per page (default: 50)
- `offset` (number): Pagination offset (default: 0)

**Response**:
```json
{
  "data": [
    {
      "id": "bnt_123",
      "issue_url": "https://github.com/org/repo/issues/42",
      "amount": "100.00",
      "currency": "USDC",
      "status": "active",
      "created_at": "2024-01-15T10:30:00Z",
      "deadline": "2024-02-15T10:30:00Z",
      "contributor": "github:octocat",
      "conditions": ["tests_passing", "code_review"]
    }
  ],
  "pagination": {
    "total": 150,
    "limit": 50,
    "offset": 0
  }
}
```

## Webhook Events

### Event Types

```json
{
  "id": "evt_123",
  "type": "bounty.created",
  "data": {
    "id": "bnt_123",
    "issue_url": "https://github.com/org/repo/issues/42",
    "amount": "100.00",
    "currency": "USDC"
  },
  "created_at": "2024-01-15T10:30:00Z"
}
```

### Available Events

- `bounty.created` - New bounty created
- `bounty.funded` - Bounty fully funded
- `bounty.claimed` - Bounty claimed by contributor
- `bounty.completed` - Bounty completed and paid
- `bounty.cancelled` - Bounty cancelled
- `transaction.completed` - Transaction completed
- `organization.updated` - Organization settings changed

### Webhook Security

Verify webhook signatures:

```javascript
const crypto = require('crypto');

function verifySignature(payload, signature, secret) {
  const hmac = crypto.createHmac('sha256', secret);
  const digest = hmac.update(payload).digest('hex');
  return crypto.timingSafeEqual(
    Buffer.from(signature),
    Buffer.from(digest)
  );
}

// Usage
const isValid = verifySignature(
  request.rawBody,
  request.headers['x-trustless-signature'],
  process.env.WEBHOOK_SECRET
);
```

## Error Handling

### Error Response Format

```json
{
  "error": {
    "code": "invalid_request",
    "message": "Amount must be greater than 10",
    "param": "amount",
    "type": "validation_error"
  }
}
```

### Error Codes

| Code | Description |
|------|-------------|
| `invalid_request` | Malformed request |
| `authentication_required` | Missing or invalid auth |
| `insufficient_permissions` | Lacks required scopes |
| `resource_not_found` | Requested resource doesn't exist |
| `rate_limit_exceeded` | Too many requests |
| `internal_error` | Server error |

## SDK Examples

### JavaScript/TypeScript

```typescript
import { TrustlessOSS } from '@trustless-oss/sdk';

const client = new TrustlessOSS({
  apiKey: 'your-api-key',
  // Optional configuration
  timeout: 30000,
  maxRetries: 3,
});

// Create a bounty
const bounty = await client.bounties.create({
  issueUrl: 'https://github.com/org/repo/issues/42',
  amount: '100.00',
  currency: 'USDC',
  deadline: '30d',
});

// List bounties with pagination
const { data, pagination } = await client.bounties.list({
  organization: 'my-org',
  status: 'active',
  limit: 10,
});
```

### Python

```python
from trustless_oss import Client

client = Client(api_key='your-api-key')

# Async support available
async def create_bounty():
    bounty = await client.bounties.create(
        issue_url='https://github.com/org/repo/issues/42',
        amount='100.00',
        currency='USDC'
    )
    return bounty

# Webhook verification
from trustless_oss.webhooks import verify_signature

def handle_webhook(request):
    payload = request.body
    signature = request.headers['X-Trustless-Signature']
    
    if verify_signature(payload, signature, 'your-secret'):
        # Process webhook
        pass
```

### Go

```go
package main

import (
    "context"
    "fmt"
    "log"
    
    trustless "github.com/trustless-oss/go-sdk"
)

func main() {
    client := trustless.NewClient("your-api-key")
    
    ctx := context.Background()
    
    // Create bounty
    bounty, err := client.Bounties.Create(ctx, &trustless.CreateBountyParams{
        IssueURL: "https://github.com/org/repo/issues/42",
        Amount:   "100.00",
        Currency: "USDC",
    })
    
    if err != nil {
        log.Fatal(err)
    }
    
    fmt.Printf("Created bounty: %s\n", bounty.ID)
}
```
