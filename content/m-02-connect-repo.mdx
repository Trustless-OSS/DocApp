# 2. Connect a repository


**What you'll do:** Install the TOSS GitHub App on your repositories, then sync them into the dashboard.

TOSS reads issues, labels, assignments, and PRs through a GitHub App installation, and receives signed webhooks for each event. Installing the App is what grants that access.

---

## Install and sync

<Steps>
### Click "Add repository"
From the dashboard, this opens the GitHub App installation page.

### Choose repositories on GitHub
Install on **all** repos, or select specific ones. You can change this later in GitHub's installed-apps settings. Private and forked repos are skipped — TOSS syncs public, non-fork repos.

### Return to the dashboard
After installing, you land back on the dashboard. Your repos appear in the Repositories list.

### Press Sync if a repo is missing
The **Sync** (refresh) button pulls the latest installation state from GitHub. Use it if a freshly installed repo hasn't appeared yet.
</Steps>

<Callout type="info">
**Only public, non-fork repos sync.** If a repo you installed on doesn't show up, confirm it's public and not a fork, then press **Sync**.
</Callout>

---

## Filters and search

The Repositories list supports search, filters (All / Deployed / Not deployed / Newest / Name A–Z), and pagination at 15 per page — handy once you've connected several repos.

---

## Done when

Your repository appears in the dashboard with status **Not deployed**. The App is installed and TOSS is receiving its events.
