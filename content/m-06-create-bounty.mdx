# 6. Create a bounty


**What you'll do:** Label an issue so TOSS reserves a reward from your escrow and opens the bounty.

A bounty always needs two things: the `rewarded` label (which turns the issue into a bounty) and an amount (from a tier label or set manually).

---

## Option A — Priced by tier

<Steps>
### Open the issue on GitHub
Pick the issue you want to fund.

### Add `rewarded`
This marks the issue as a bounty.

### Add a tier label
Add `low`, `medium`, `high`, or any tier you configured. TOSS reserves that tier's USDC amount from the escrow balance.
</Steps>

## Option B — Manual amount

Use this for a one-off amount that doesn't fit a tier.

<Steps>
### Add `rewarded` + `manual`
This creates the bounty in an **unpriced** state — no funds reserved yet.

### Set the amount
Comment the amount, or put it in the issue body before labeling.
</Steps>

<CommandBlock
  command="@trustless-oss 150"
  description="Sets the manual reward to 150 USDC and reserves it from escrow. 'USDC' after the number is optional."
  where="Comment on the bounty issue"

## What the bot confirms

Once an amount is set, the bot comments with the reward, the level, and a link to view the escrow on-chain. For an unpriced `rewarded` issue, it instead tells you to add a tier label or a manual amount.

| Issue state | Bot comment |
| --- | --- |
| `rewarded` only, no amount | "Bounty Created — no reward set yet. Add a label or comment an amount." |
| `rewarded` + tier | "Bounty Created — the reward in USDC, with the tier as the level." |
| `rewarded` + `manual` + amount | "Bounty Created — the reward in USDC, level `manual`." |
| Escrow too low for the amount | "Insufficient Escrow Balance — top up." |

---

## Changing the amount later

You can relabel or re-comment a new amount **as long as the bounty hasn't locked on-chain** — that is, while it's still open, or assigned but without a connected contributor wallet yet. After the milestone is pushed on-chain, the amount is fixed.

<Callout type="warning">
Only the escrow's available balance can be reserved. If you label a bounty larger than the escrow's free balance, the bot refuses it and asks you to [fund the escrow](/m-04-fund-escrow) first. Funds already reserved by other open bounties are not available.
</Callout>

---

## Done when

The bot has commented confirming the reward amount and level, and the issue shows `rewarded` + its tier (or `manual`).
