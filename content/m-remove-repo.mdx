# Remove a repository


**What you'll do:** Disconnect a repository from TOSS and clean up its GitHub App connection.

---

## Requirement: zero balance

You can only remove a repo when its escrow balance is **0 USDC**. If there's any balance, [withdraw it first](/m-withdraw) — the backend refuses deletion while funds remain.

---

## What removal does

<Steps>
### Deletes TOSS records for the repo
Tracked issues, bounty records, and reward tiers for this repo are removed.

### Revokes GitHub App access
If this was the **last** repo on the installation, the GitHub App is uninstalled entirely. Otherwise, just this repo is removed from the installation.

### Leaves your code untouched
Your issues, PRs, and remaining labels stay on GitHub. TOSS simply stops watching the repo.
</Steps>

<Callout type="warning">
Removal deletes TOSS's bounty records and reward tiers for the repo and revokes App access. It doesn't touch your code, issues, or PRs, but the bounty history inside TOSS for this repo is gone. This can't be undone — you'd reconnect from scratch.
</Callout>

---

## Reconnecting later

Reinstall the GitHub App and connect the repo again. You'll deploy a fresh escrow and set up tiers from scratch.
