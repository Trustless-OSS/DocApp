# Choose a wallet


**What you'll do:** Pick a Stellar wallet. You'll use it to hold USDC and sign TOSS transactions (connect, deploy, fund).

Any Stellar wallet that supports USDC works. TOSS integrates with Freighter, xBull, Albedo, LOBSTR, and Rabet. If you don't already have one, start with the recommended default.

---

## Recommended: LOBSTR

Mobile and web, beginner-friendly, maintained by a Stellar-focused team, and the wallet TOSS links for contributors without one. Pick this unless you have a reason not to.

**Next:** [Create your wallet](/create-wallet) with LOBSTR.

## Other supported wallets

<details>
  <summary className="font-semibold cursor-pointer">Freighter — browser extension (desktop)</summary>
  <div className="mt-2 text-sm text-gray-600 dark:text-gray-400">
    Chrome/Firefox/Brave extension from freighter.app. Good if you prefer signing in the browser. Desktop only.
  </div>
</details>

<details>
  <summary className="font-semibold cursor-pointer">xBull — web + mobile</summary>
  <div className="mt-2 text-sm text-gray-600 dark:text-gray-400">
    Multi-platform (xbull.app), with a browser extension and mobile apps.
  </div>
</details>

<details>
  <summary className="font-semibold cursor-pointer">Albedo — web signer</summary>
  <div className="mt-2 text-sm text-gray-600 dark:text-gray-400">
    Browser-based signer (albedo.link); no install. Handy for occasional signing.
  </div>
</details>

<details>
  <summary className="font-semibold cursor-pointer">Rabet — browser extension (desktop)</summary>
  <div className="mt-2 text-sm text-gray-600 dark:text-gray-400">
    Chrome/Firefox extension from rabet.io.
  </div>
</details>

<Callout type="info">
They're functionally interchangeable for TOSS. The deciding factor is usually platform: a phone wallet (LOBSTR, xBull) vs a desktop browser extension (Freighter, Rabet). The rest of these setup pages use LOBSTR as the example.
</Callout>
