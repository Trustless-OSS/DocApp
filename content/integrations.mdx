# Integrations

Trustless OSS integrates seamlessly with your existing development workflow and tools.

## GitHub Integration

### GitHub App

The Trustless OSS GitHub App provides deep integration with your repositories:

```yaml
# .github/trustless-oss.yml
version: 1

# Repository settings
settings:
  auto_label_issues: true
  minimum_bounty_amount: 25
  allowed_currencies: ["USDC", "EURC"]
  
# Bounty templates
templates:
  bug_fix:
    base_amount: 50
    labels: ["bug", "bounty"]
    priority: high
    
  feature:
    base_amount: 100
    labels: ["enhancement", "bounty"]
    priority: medium
    
  documentation:
    base_amount: 25
    labels: ["documentation", "bounty"]
    priority: low
```

### Features

- **Automatic issue labeling**: Tag issues with `bounty` based on templates
- **PR status checks**: Verify bounty conditions before merge
- **Comment commands**: Use `/bounty claim`, `/bounty status` in issue comments
- **Webhook events**: Receive notifications for all bounty activities

### Installation

1. Install the GitHub App: [https://github.com/apps/trustless-oss](https://github.com/apps/trustless-oss)
2. Configure repository permissions
3. Set up webhooks (optional)

## Stellar Integration

### Wallet Integration

Connect your Stellar wallet for funding and receiving payments:

```javascript
import { TrustlessOSS } from '@trustless-oss/sdk';

const trustless = new TrustlessOSS({
  network: 'testnet', // or 'mainnet'
  wallet: {
    type: 'freighter', // or 'albedo', 'rabet', 'walletConnect'
    publicKey: 'your-public-key'
  }
});

// Check balance
const balance = await trustless.getBalance('USDC');

// Fund a bounty
const tx = await trustless.fundBounty({
  bountyId: 'bounty-123',
  amount: '100',
  currency: 'USDC'
});
```

### Supported Wallets

- **Freighter**: Browser extension wallet
- **Albedo**: Web-based wallet
- **Rabet**: Mobile-first wallet
- **WalletConnect**: Multi-chain compatibility
- **Ledger**: Hardware wallet support

### Smart Contract Interaction

```rust
// Interacting with Trustless OSS smart contracts
use trustless_oss_contract::{TrustlessOSS, Bounty};

#[derive(Serde)]
struct BountyParams {
    issue_url: String,
    amount: i128,
    deadline: u64,
    conditions: Vec<Condition>,
}

fn create_bounty(params: BountyParams) -> Result<(), Error> {
    let contract = TrustlessOSS::new();
    contract.create_bounty(params)
}
```

## CI/CD Integration

### GitHub Actions

```yaml
# .github/workflows/trustless-bounty.yml
name: Trustless Bounty Verification

on:
  pull_request:
    types: [opened, synchronize, reopened]

jobs:
  verify-bounty:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      
      - name: Check bounty requirements
        uses: trustless-oss/verify-bounty@v1
        with:
          github-token: ${{ secrets.GITHUB_TOKEN }}
          trustless-token: ${{ secrets.TRUSTLESS_TOKEN }}
          
      - name: Run security scans
        if: ${{ steps.verify-bounty.outputs.has_bounty == 'true' }}
        run: |
          npm audit
          snyk test
          
      - name: Check test coverage
        if: ${{ steps.verify-bounty.outputs.has_bounty == 'true' }}
        run: |
          npm test -- --coverage
          # Ensure coverage meets bounty requirements
```

### Usage Examples

```python
# Python example
from trustless_oss import Client

client = Client(
    api_key="your-api-key",
    base_url="https://api.trustless-oss.xyz"
)

# List organization bounties
bounties = client.bounties.list(org="your-org")

# Create webhook
webhook = client.webhooks.create(
    url="https://your-app.com/webhooks/trustless",
    events=["bounty.created", "bounty.completed"]
)
```

```go
// Go example
package main

import (
    "context"
    "fmt"
    trustless "github.com/trustless-oss/go-sdk"
)

func main() {
    client := trustless.NewClient("your-api-key")
    
    ctx := context.Background()
    bounties, err := client.Bounties.List(ctx, &trustless.ListBountiesOptions{
        Organization: "your-org",
        Status:       trustless.BountyStatusActive,
    })
    
    if err != nil {
        panic(err)
    }
    
    fmt.Printf("Found %d active bounties\n", len(bounties))
}
```

## Webhook Events

Subscribe to real-time events:

```javascript
// Example webhook handler
app.post('/webhooks/trustless', async (req, res) => {
  const signature = req.headers['x-trustless-signature'];
  const isValid = verifySignature(signature, req.body);
  
  if (!isValid) {
    return res.status(401).send('Invalid signature');
  }
  
  const event = req.body;
  
  switch (event.type) {
    case 'bounty.created':
      await notifySlack(`🎯 New bounty: $${event.data.amount} for ${event.data.repository}`);
      break;
      
    case 'bounty.claimed':
      await updateDatabase(event.data.bountyId, {
        status: 'claimed',
        claimant: event.data.contributor
      });
      break;
      
    case 'bounty.completed':
      await sendCongratsEmail(event.data.contributor, event.data.amount);
      break;
  }
  
  res.status(200).json({ received: true });
});
```
