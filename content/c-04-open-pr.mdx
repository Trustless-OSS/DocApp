# 4. Open a PR

<TimeEstimate minutes={5} forRole="Contributors" needs="Work completed + Git and GitHub" />

**What you'll do:** Push your work and open a pull request that closes the bounty issue.

---

## Step 1: Commit your work

Follow the repository's contribution guidelines. Commit your changes:

```bash
git add .
git commit -m "Fix: description of your work"
git push origin your-branch-name
```

---

## Step 2: Open a PR on GitHub

Go to the repository on GitHub. Click **"New Pull Request"**.

  type: image

  show: GitHub repository page with "New Pull Request" button
  caption: Click to create a new PR
  alt: New PR button
*/}

---

## Step 3: Select your branch

Choose your feature branch (where you pushed your code).

{/* MEDIA-SLOT
  id: c-pr-02
  type: image
  file: /media/contributor/github-branch-select.png
  show: PR creation page with branch selector (main ← your-branch)
  caption: Select your branch with the work
  alt: Branch selector
*/}

---

## Step 4: Link the issue in the PR description

In the PR description, add a line that links to the bounty issue:

```
Closes #123
```

Or use these alternatives:
```
Fixes #456
```
```
Resolves #789
```

{/* MEDIA-SLOT
  id: c-pr-03
  type: image
  file: /media/contributor/github-pr-description.png
  show: PR description field with "Closes #123" at the top
  caption: Add "Closes #N" to link the issue
  alt: PR description with issue link
*/}

<Callout type="warning">
  **This is critical.** Without the "Closes" link, the system won't detect that your PR closes the bounty issue. The payout won't trigger.

  Check: PR description includes `Closes #N` (where N is the issue number).
</Callout>

---

## Step 5: Describe your work

Write a brief description of what you did:
- What problem does it solve?
- How did you test it?
- Any breaking changes?

---

## Step 6: Click "Create Pull Request"

Submit the PR.

{/* MEDIA-SLOT
  id: c-pr-04
  type: image
  file: /media/contributor/github-pr-submit.png
  show: PR creation page with "Create Pull Request" button
  caption: Submit your PR
  alt: Submit PR button
*/}

---

## The maintainer reviews your work

- They'll review the code
- They may request changes
- You can push more commits to the same branch (PR updates automatically)

---

## Done when

Your PR is open, linked to the issue (shows "Closes #N"), and ready for review.
